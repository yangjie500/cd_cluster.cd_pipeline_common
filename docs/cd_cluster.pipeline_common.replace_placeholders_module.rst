cd_cluster.pipeline_common.replace_placeholders
***********************************************

**Replace custom tokens or text placeholders inside a file**



.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Searches for specified text placeholders or variables in a target file and replaces them with defined values.
- Supports default angle-bracket tokens (<key>), Jinja2-style placeholders ({{ key }}), and custom word boundaries.
- Safely handles local backups and respects Ansible check-mode dry runs.

Examples
--------

.. code-block:: yaml

    - name: Replace standard <key> placeholders with target values
      replace_placeholders:
        path: helm-charts/vault.values.yaml
        placeholders:
          container_registry_url: "xxx/mario/backend_preprod"
          repository_url: "xxx/mario/backend_preprod"

    - name: Replace Jinja-style placeholders dynamically
      replace_placeholders:
        path: /etc/app/config.conf
        jinja_tokens: true
        case_sensitive: false
        placeholders:
          db_host: "10.0.0.5"
